# 运营操作手册：面板怎么用、表里每一列什么意思

给日常盯表的运营看的。不讲原理、不讲部署，只讲三件事：这套东西怎么转、
面板上每个东西怎么用、飞书表里每一列谁填、什么意思、看到了怎么办。
技术细节在 `docs/表结构.md` 和 `docs/面板.md`，这里不重复。

---

## 一、先记住这四句

1. **你只填 6 列**：反馈链接、发布时间、评论关键词、负面词、是否巡查、排队刷新。其余带「机器」标记的列不要手改。
2. **机器自己按节奏刷**：发布 0–2 天每 8 小时一次，3–7 天每天一次，8–30 天每 3 天一次，超过 30 天不再自动刷。
3. **面板负责发现，飞书负责处理**：先看面板「要人管的行」，点「去这一行」落到飞书里处理。
4. **想现在就刷某一行**：在飞书里勾「排队刷新」，五分钟内刷完，勾自动消失。

---

## 二、这套东西怎么运转

```
你在飞书表里贴链接、填发布时间、勾「是否巡查」
        ↓
机器每 5 分钟起来一次，挑出到期的行，去平台拉第一页评论
        ↓
把评论数、各种状态、评论区快照、诊断信息写回那一行，盖上「最近检查时间」
        ↓
面板每分钟汇总所有表，把要人管的行列在一屏上
```

几个要知道的边界：

- **只看第一页评论**（小红书和抖音都是）。翻页按页计费，所以埋在第二页以后的评论看不到。
- **每次刷新都花钱**（一次几分到一毛）。所以有节奏、有预算、有各种闸门，不会因为一次手滑刷爆。
- **结案了就勾掉「是否巡查」**，这一行从此一分钱不花。整个项目结案就在面板上「停用」这张表。

## 三、监控面板怎么用

登录用运营共用的口令。页面从上到下是：顶部四个数 → 要人管的行 → 各项目 → 项目管理 → 余额 → 运行历史。左侧栏可以直接跳。

### 3.1 顶部四个数

| 数字 | 什么意思 | 看到它该做什么 |
|---|---|---|
| **要人管** | 所有表里需要人处理的行数（下面待办列表的总行数） | 这是面板存在的理由。每天看一眼，处理掉 |
| 下一轮预计花费 | 按分层节奏，现在已经到期该刷的行有多少、刷一遍多少钱 | 只是背景信息。cron 每 5 分钟一轮，任何时候都有一批刚到期的，**这个数大不是问题** |
| 余额还够跑 | 按最近几轮的实际花速算出来的天数 | 变黄（≤14 天）就该安排充值，变红（≤5 天）马上充 |
| 卡住了 | 超过应有间隔两倍还没被刷到的行 | **这个数不为零才要查**：多半是预算顶了、一直报错、或调度没在跑。截图给技术 |

### 3.2 要人管的行

每个项目一个标签页，标签上的数字是这个项目要人管的行数（红色 = 里面有风控 / 失效 / 刷新失败）。页内按严重程度排，**排序就是处理顺序**：

| 为什么 | 什么意思 | 怎么处理 |
|---|---|---|
| 风控中 | 平台给了审核 / 受限标记，或链接连续两次取不到内容 | **人工去平台确认**帖子还在不在、能不能搜到。确认没了就勾掉「是否巡查」 |
| 已失效 | 链接连续两次取不到内容 | 同上 |
| 刷新失败 | 网络 / 接口故障，**表里已有的数据一个都没动** | 看「诊断信息」。一两行不用管，下一轮自动重试；一整批同时失败是通道问题，通知技术 |
| 有负面 | 第一页评论里出现了负面词或竞品词 | 去飞书看「负面评论快照」，按公关流程处理 |
| 疑似限流 | 评论数比上次腰斩（跌 ≥ 50%，且之前 ≥ 20 条） | 去平台看是删评、折叠还是限流 |
| 疑似受限 | 第一次取不到内容，还没定罪 | 先不用动，下一轮自动复核；两次都取不到才判失效 |
| 置顶掉了 | 以前置顶成功过，现在第一页没有置顶了 | 去补置顶 |
| 卡住了 | 见上 | 截图给技术 |

每一行有五栏：

- **哪一条**：笔记内容的前十来个字。拿它去飞书表里 Ctrl+F 定位最快。
- **为什么**：上面那张表里的原因。
- **诊断信息**：机器写的人话解释。
- **最近检查**：上次刷的时间。旁边带「排队中」标记，说明勾了排队刷新、还没刷回来，**看到的还是旧结论**。
- **去这一行**：直达飞书里的那一行。

自上次打开面板以来新出现的待办带一个「新」字。新增才是要看的，总量每天差不多。

顶栏的筛选框跨所有项目筛。筛「风控」，每个标签上的数字就变成这个项目里命中的行数。

**面板默认不显示评论正文**（那是别人写的东西，有个人信息）。要看内容，点「去这一行」到飞书里看快照。

### 3.3 批量勾「排队刷新」

待办列表每行前面有勾选框，勾完点「勾『排队刷新』」。规则：

- 表头的「全选」只选**当前这个项目**里没被筛掉的行。切换项目标签会清掉上一页的勾，要给几个项目都勾就一个项目一个项目来。
- 一次最多 200 行。勾一行就是花一次钱。
- 勾成功的行立刻标「排队中」。cron 五分钟内接手，**标记消失、「最近检查」变新，才是刷回来的新结论**。
- **新表第一次勾一批会「刷了 50 行就停」**，不是坏了。全新的表一轮只刷前 50 行，剩下的勾留着，下一轮再来 50 行，几轮就铺满。
- 已停用 / 已移除的表勾不了，面板会拒绝并说明。
- 已归档的老帖（发布超过 30 天）折在下面单独一区，不在批量勾的范围里。老帖多数时候正确的处置是去飞书取消巡查，不是再花钱刷一次。

### 3.4 各项目

每张表一张卡：在管多少行、要人管几行、到期待刷几行（多少钱）、排队中几行、卡住几行。

卡上还有一行「**没填发布时间**」，**只在不为零的时候出现**，数的是勾了「是否巡查」、但「发布时间」那一格空着的行。看到它就去把那几行的发布时间补上：帖龄算不出来的行**永远不会归档**，会按最快的一档（8 小时）一直刷下去，一直花钱。没勾巡查的行不算在里面（那多半是还没发的草稿）。

四个按钮：

| 按钮 | 干什么 |
|---|---|
| 补齐缺的列 | 表里少了机器要用的列，点它自动建上。只加不改，已有的列一个不碰 |
| 停用 / 启用 | 停用 = cron 下一轮不刷它了，随时可以开回来。**不动飞书表里任何数据** |
| 阈值 | 逐表改评估中 / 爆贴 / 大爆的评论数门槛（默认 20 / 50 / 100）、无水花小时（默认 48）、归档天数（默认 30）。改完下一轮生效。保存前先点「先算给我看」，它会告诉你有几行档位会变 |
| 移除 | 从清单里去掉，不再监控。**飞书表里的数据一个字都不动**。面板没有删表的按钮 |

### 3.5 项目（加表）

两条路，都不花钱：

- **接管一张已有的表**：粘表格链接 → 「体检一下」→ 体检说缺列就点「补齐缺的列」，说类型建错的要人去飞书改 → 「加进清单」→ 加进来默认**不启用**，体检全绿再点「启用」。
- **从零新建一张**：填项目名 → 「直接新建一张」→ 连业务列一起按标准业务表建齐，链接自动填进输入框 → 「体检一下」→ 「加进清单」→ 「启用」。

新建的表要给谁开权限：同一栏里点「选群」勾上运营群，群里的人就都能编辑。可管理的人由后台固定配置，面板上只显示「后台已配 N 人」。

体检说「读不到这张表的字段列表」只能你来做：表格右上角 `···` → 更多 → 添加文档应用 → 搜应用名 → 权限「可编辑」。开了高级权限的还要再给「可管理」。

### 3.6 余额

两家数据通道各一块：余额、每天花多少、还够跑几天。**读不到就写读不到，不会显示 ¥0**。真的为 0 要去充值，读不到是 Key 或网络的问题，两件事完全不同。看余额本身不花钱。

### 3.7 运行历史

每一轮什么时候开跑、刷了哪些表、多少行、花了多少、有没有熔断，以及「跑完剩」多少余额。标着「没跑完」的轮子是被容器中途杀掉的，那一轮的结果多半丢了，偶尔一次不用管，连续出现通知技术。最多能看 7 到 30 天。

### 3.8 其他

- 「重新取数」：面板每分钟自动刷，等不及就点它。
- 右下角月亮按钮切换深浅模式，只影响你自己的浏览器。
- 「新」标记和上次看的项目标签存在你自己的浏览器里，换浏览器就重来。

## 四、飞书表里的每一列

四组：你填的、机器写的、蓝词三件套、系统列。业务列（素人编号、方向、文案、配图、笔记状态……）机器完全不读不写，随便加减。

**不要改机器列的列名和类型。** 列名差一个字机器就找不到那一列；类型建错机器写不进去。表里少了列，去面板点「补齐缺的列」。

### 4.1 你填的列

| 列 | 类型 | 填什么 | 注意 |
|---|---|---|---|
| **反馈链接** | 文本 | 原样粘贴分享文案或链接。小红书 `xhslink.com` 短链、抖音 `v.douyin.com` 短链都直接可用 | 别改成「超链接」类型，它会吞掉短链里的参数 |
| **发布时间** | 日期 | 帖子的发布日期 | **一定要填。** 空着的行按最快节奏（每 8 小时）刷、永远不归档，一直花钱；而且判不了热度档位，「流量状态」会空着。面板项目卡上的「没填发布时间」就是数这种行的 |
| **评论关键词** | 多选或文本 | 我们自己种的评论里的关键词，一组词，任一词出现在第一页任一条评论里就算「显示了」 | 没填这一列的行，机器不碰「评论状态」。多个词用顿号 / 逗号分开。不区分大小写和标点 |
| **负面词** | 多选或文本 | 负面词 + 竞品词，格式同上 | 没填这一列的行，机器不碰「负面状态」和「负面评论快照」。方向和上一列正好相反：上一列希望命中，这一列不希望命中 |
| **是否巡查** | 复选框 | 勾上才刷。**结案就勾掉**，永久止损 | 取消勾选的行在面板上也不算在管 |
| **排队刷新** | 复选框 | 勾上 = 我现在就要这一行的数据。五分钟内刷完，勾自动消失 | 勾消失就是刷完了。不看「是否巡查」，结案的表里临时查一行也管用。同一行 90 秒内连勾多次只算一次 |

### 4.2 机器写的列

| 列 | 类型 | 什么意思 | 怎么看 |
|---|---|---|---|
| **平台** | 单选 | 小红书 / 抖音，按链接自动识别 | |
| **实时数据.评论数** | 数字 | 这一轮拉到的评论总数（含回复） | 热度档位全靠它 |
| 上次评论数 | 数字 | 上一轮的评论数 | 算增量用，建议隐藏 |
| 评论增量 | 公式 | 实时评论数 − 上次评论数 | 「今天谁涨得最猛」按它排序 |
| **起量时间** | 日期 | 这一行**第一次**被判为起量的时刻：评论数比上次涨 ≥ 50% 且多 ≥ 20 条 | 只写第一次，后面涨再猛也不覆盖。想让它重新计一次，手工清空这一格。第一次巡查不算起量 |
| **流量状态** | 多选 | 热度档位 + 异常标签，见第五节 | 人机共用。机器只碰它自己的七个词，「爆帖预备」这类人工值随便打，机器不动 |
| **评论状态** | 单选 | 我们的评论显示出来了吗：显示评论 / 没有显示 | 由「评论关键词」驱动。没填关键词就空着 |
| **评论区快照** | 文本 | 第一页综合排序的前 8 条评论，每条最多 40 字 | 命中关键词的那条排第一行、带「命中『词』」标记，然后是置顶那条，其余接后。**顺序是平台的热评排序，不是你手机上看到的顺序**，见第六节 |
| **负面状态** | 单选 | 有负面 / 无负面 | 由「负面词」驱动。只看第一页，是预警不是普查。自家账号的回复不算（抖音上分不出作者，这个排除等于没开） |
| **负面评论快照** | 文本 | 只放命中负面词的那几条，每条标出命中的是哪个词 | 判过但一条没中写「（未命中）」；空着 = 这一轮压根没查 |
| **置顶状态** | 单选 | 置顶成功 / 置顶掉了 / 无置顶 | **只有小红书有**，抖音行永远空着。「掉了」= 以前成功过现在没了，一直不恢复就一直是「掉了」 |
| **巡查状态** | 单选 | 这一轮机器跑得怎么样，见第五节 | 「正常」以外的都值得看一眼「诊断信息」 |
| **诊断信息** | 文本 | 人话解释：为什么打这个标签、哪一格填得有问题、上游报了什么错 | 看不懂就整格截图给技术，里面带排查用的编号 |
| **最近检查时间** | 日期 | 这一行上一次刷完的时刻 | **不要手改、不要清空。** 清空 = 下一轮全表重刷一遍，直接烧钱 |
| 下次检查时间 | 公式 | 按分层节奏算出来的下一次刷的时刻 | 发布超过 30 天显示空（归档了，不再自动刷）。只是预告，实际以「最近检查时间」为准 |
| 已确认存活 | 复选框 | 这一轮真的量到了数字（哪怕是 0）就勾上；连续两次确认失效就取消 | 一般不用看 |
| 连续失败次数 | 数字 | 连续几轮取不到内容。两次判失效 | 系统列，建议隐藏 |

### 4.3 蓝词三件套

蓝词 = 评论里被平台变成搜索超链接的词。

| 列 | 类型 | 谁写 | 规则 |
|---|---|---|---|
| **蓝词字段** | 多选 | 人机共用 | 机器扫到表里还没有的蓝词就**追加**进来，只加不减，你自己填的原样保留 |
| **是否截图** | 单选 | 机器只写「未截图」 | 有新蓝词那一轮翻成「未截图」。你去手机上截图放进「蓝词图片」，**手动改回「已截图」**。没有新词的轮次机器不碰它，不会把你刚改的撤销掉 |
| **蓝词图片** | 附件 | 人工 | 放蓝词截图 |

有新蓝词时「诊断信息」里会多一句「🔵 评论里出现新蓝词：xx（已加进「蓝词字段」，请截图）」。

**只对小红书生效。** 抖音的蓝词不随评论一起下发，两家数据通道都拿不到，抖音行的「蓝词字段」要人工填、人工截图。

## 五、每个状态值的意思

### 流量状态（多选）

热度五档互斥、**只升不降**：爆过就是爆过，评论被删掉数字掉下去不会退档，那种异常由「疑似限流」表达。

| 值 | 什么时候打 |
|---|---|
| 观察中 | 发布不满 48 小时、评论不足 20 条。**还没到下结论的时候**，不是没起来。到点自动升档 |
| 无水花 | 发布满 48 小时评论仍不足 20 条。没起来，不是异常 |
| 评估中 | 评论 ≥ 20 |
| 爆贴 | 评论 ≥ 50 |
| 大爆 | 评论 ≥ 100 |
| 风控中 | 平台给了审核 / 受限标记，或链接连续两次取不到。**只认硬证据**，评论数的涨跌不算。⚠️ 「发帖人自己看得到、别人点开是笔记不存在」这种**目前抓不到**（要多调一个接口，成本原因默认关着），发现了要靠人工点链接确认，**自己把「风控中」打上即可，机器不会摘** |
| 疑似限流 | 评论数比上次腰斩（跌 ≥ 50%，之前 ≥ 20 条） |
| 爆帖预备 | 人工值，机器不碰 |

**风控中、疑似限流机器只加不减。** 这两个标签一旦在行上，不管是机器打的还是你打的，机器每轮都原样保留，只会在自己判定成立时加上去。所以你人工判定的风控不会被下一轮的「无水花」覆盖。反过来也一样：帖子恢复了这两个标签不会自己消失，处理完记得去飞书把它摘掉，不然面板「要人管的行」里会一直挂着。

三个门槛可以在面板「阈值」里逐表改。

### 巡查状态（单选）

| 值 | 什么意思 |
|---|---|
| 正常 | 这一轮拉到了数据 |
| 疑似受限 | 第一次取不到内容，还没定罪，下一轮复核 |
| 已失效 | 连续两次取不到，判失效。「流量状态」同时打「风控中」 |
| 刷新失败 | 网络 / 接口故障，表里已有数据没动。一批同时失败会触发熔断：记一次、1 小时后自动复查，第二次仍取不到才判失效 |
| 跳过 | 链接解析不出来，或这家通道不吃这种链接。看「诊断信息」 |

### 评论状态 / 负面状态 / 置顶状态 / 是否截图

| 列 | 值 |
|---|---|
| 评论状态 | 显示评论 / 没有显示 |
| 负面状态 | 有负面 / 无负面 |
| 置顶状态 | 置顶成功 / 置顶掉了 / 无置顶（抖音不写） |
| 是否截图 | 未截图（机器写）/ 已截图（人改） |

## 六、常见情况

**「流量状态」空着。** 三种可能：还没轮到它（看「最近检查时间」是不是空的）；「发布时间」没填（看「诊断信息」，会明说）；「流量状态」列里没建「观察中」这个选项（面板项目卡会报缺选项）。

**面板项目卡上出现「没填发布时间 N 行」。** 那 N 行勾着巡查、发布时间却是空的。它们不会进「要人管」的列表，也不算「卡住了」，但每 8 小时就刷一次、永远不停。去飞书把发布时间补上，下一轮就归位；确实不该再管的行就勾掉「是否巡查」。

**「评论状态」「负面状态」空着。** 那一行没填「评论关键词」/「负面词」。面板上「关键词覆盖度」那一行会数出来有几行没填。

**「刷新失败」。** 看「诊断信息」。一两行不用管，下一轮自动重试。一整批同时失败是数据通道的问题，通知技术；机器会自动记一次、1 小时后复查。

**「疑似受限」。** 先不用动，下一轮自动复核。两次都取不到才判「已失效」+「风控中」。

**「已失效」「风控中」。** 人工去平台确认。帖子真没了就勾掉「是否巡查」，别让它继续花钱。

**链接别人点开是「笔记不存在」，机器却判「正常」。** 这是笔记被限制成只有发帖人自己看得到。机器默认只调评论接口，评论还在就判正常；能看出这种情况的详情接口因为成本原因默认关着。所以怀疑限流时自己点一下分享链接最可靠，确认了就在「流量状态」里手动打上「风控中」，机器不会摘，面板也会把这一行列进「要人管的行」。

**「置顶掉了」。** 去补置顶。补好后下一轮自动变回「置顶成功」。

**「风控中」「疑似限流」处理完了还挂着。** 正常，这两个标签机器只加不减。处理完去飞书把它摘掉，面板上这一行就不再是待办。

**「是否截图」变成「未截图」。** 看「蓝词字段」里新加的词，去手机上截图放进「蓝词图片」，改回「已截图」。

**快照里的评论和我手机上看到的不一样。** 三个原因：快照把命中的那条和置顶挪到最前；接口返回的是平台的热评排序、不带个人化，而你手机上会把自己和关注的人的评论排前面；快照是上次刷的时候的样子，有时间差。都不是错。

**勾了「排队刷新」没动静。** 按顺序查：cron 五分钟一轮，等够五分钟了吗；新表一轮只刷 50 行，你勾的是不是在后面；这张表在面板上是不是停用了；同一行 90 秒内刚刷过会被跳过。

**「起量时间」一直空着。** 正常。它只在评论数比上次涨 ≥ 50% 且多 ≥ 20 条的那一轮写一次，第一次巡查不算，没起过量就一直空。

**抖音行「置顶状态」「蓝词字段」空着。** 正常。抖音接口没有置顶字段，蓝词也拿不到，这两列抖音行要人工判、人工填。

**结案。** 单行结案勾掉「是否巡查」；整个项目结案在面板上「停用」这张表。两种都不会动表里已有的数据。

## 七、别做的事

- 别改机器列的列名、类型、选项名。
- 别手动清空「最近检查时间」，下一轮会全表重刷。
- 别手动填「巡查状态」「评论状态」「负面状态」「置顶状态」，下一轮会被覆盖。
- 别在「流量状态」里手动打热度档位那五个词（观察中 / 无水花 / 评估中 / 爆贴 / 大爆），机器会按自己的判断改掉。「风控中」「疑似限流」可以手动打，机器不摘。别的人工标签用「爆帖预备」或自己新建的选项。
- 别在面板上给几个项目连着勾「排队刷新」不看数字，每勾一行都是钱。
